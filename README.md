💰 Interactive Expense Tracker

A responsive web application built with HTML, CSS, and JavaScript to manage daily expenses easily. It allows users to add, edit, delete, search, filter, and sort expenses while automatically calculating expense summaries.

✨ Features

- Add new expenses with title, amount, category, date, and notes.
- Edit and delete existing expenses.
- View total expenses, transaction count, and highest expense.
- Search expenses by title, category, or notes.
- Filter expenses by category and date.
- Sort expenses by date, amount, or name.
- Save expense data in the browser using LocalStorage.
- Responsive design for desktop and mobile screens.
- Display amounts in Indian Rupees (₹).

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Browser LocalStorage
- Responsive Web Design

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Start adding and managing your expenses.

No server or additional installation is required.

💾 Data Storage

Expenses are saved in the browser's LocalStorage, so they remain available in the same browser on the same device. Clearing browser data or using another browser may remove or make the saved expenses unavailable.

🎯 Project Objective

The objective of this project is to practice JavaScript fundamentals, CRUD operations, DOM manipulation, data filtering, sorting, browser storage, and responsive frontend development.
